# Sistema Dos

Directorio destinado a conservar la evidencia encontrada en el segundo sistema ganadero analizado.

## Propósito

Aquí se almacenarán, sin modificar los originales, los archivos, bases de datos, manuales, instaladores, ayudas y demás materiales encontrados en el Sistema Dos.

## Criterio de trabajo

- Conservar evidencia original.
- No modificar archivos fuente.
- Documentar procedencia y nombre original.
- Separar evidencia técnica de interpretación.
- Analizar estructura, datos y funcionamiento antes de reutilizar cualquier componente.

La estructura podrá ampliarse cuando aparezcan nuevos tipos de evidencia.
