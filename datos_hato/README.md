# Datos Hato

Carpeta de trabajo para el análisis, documentación y reportes relacionados con los datos operativos de Hato.

## Fuente principal

La fuente original `DATA GENERAL.xlsb` permanece en la raíz del repositorio y se conserva sin modificaciones.

## Propósito

Aquí se organizarán los materiales derivados del análisis de los datos: reportes, mapas de información, análisis funcional y documentación necesaria para relacionar los datos reales con el sistema Hato.
